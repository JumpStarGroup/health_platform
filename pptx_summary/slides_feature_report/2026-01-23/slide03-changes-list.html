功能变化清单（按模块）

2026-01-08 ~ 2026-01-23

健康记录

更严格校验 + 防重复

血压范围 30-250，且收缩压>舒张压；心率可选 30-150；同成员同分钟重复记录拦截。

导出

CSV 可用性提升

UTF-8 BOM 兼容 Excel；RFC5987 filename* 支持中文文件名；支持按成员/标签/日期过滤导出。

成员

Self/自己 保护

默认成员不可编辑/删除；Self 资料与 Profile 同步，避免主档丢失或误操作。

批量导入

Preview → Commit 流程

先预览校验，再提交写入；未知成员可映射或新建；错误/跳过行可导出报告。

质量体系

E2E 回归稳定可复现

中文 UI 主路径覆盖注册/登录/切换语言/记录/成员等；减少 flaky，提高 CI 可信度。

报告资产

PPT/HTML slides 沉淀

周报/月报与专项报告可脚本生成，支持图文呈现，便于对内/对外汇报。

结论：近期工作从“可用功能”走向“可规模化交付”，面向数据迁移、质量保障与可汇报性持续增强。
