全量功能清单（管理/平台侧）

v1.1.0

管理员能力（ADMIN / SUPER_ADMIN）

  • 用户列表：用户名/邮箱/角色/注册时间/最后登录
  • 重置密码：生成强临时密码，强制下次登录改密
  • 会话失效：通过 token_version 使旧会话失效
  • 角色管理：仅 SUPER_ADMIN 可提升/降级 ADMIN（禁止修改 SUPER_ADMIN）

安全约束：管理员不能通过管理员接口重置“自己的”密码（需走自助改密）。

工程与运维能力

  • 分层架构：Client → Service → Manager → Models
  • DB：开发 SQLite 自动建表；外部 DB 健壮性与可选 TLS
  • CLI：db-info / db-create
  • 版本接口：GET /api/v1/version（可用于登录页展示）
  • 自动化：Pytest 单测 + Playwright E2E 回归 + 报告
  • 容器化：Docker / Kubernetes 部署资产与脚本

目标：降低发版风险、提升可观测性与可交付性。
