全量功能清单（用户侧）

v1.1.0

账号与安全

  • 注册/登录：邮箱或用户名（用户名不区分大小写）
  • 密码强度：≥8位，包含字母+数字
  • Access/Refresh 双令牌：登出/登出全部会话
  • 强制改密：首次登录或被重置密码后拦截

家庭成员

  • 成员列表/创建/更新/删除（软删除）
  • 默认成员保护：Self/自己 不可编辑/删除
  • Self 与 Profile 同步（如身高）

健康记录

  • 记录 CRUD：血压（必填）、心率（可选）、标签、备注
  • 数据校验：30-250mmHg 且收缩压>舒张压；心率 30-150
  • 重复记录防护：同成员同分钟拦截
  • 筛选：按成员/日期区间/标签（OR 语义）

导出 / 导入

  • CSV 导出：UTF-8 BOM + 中文文件名支持
  • 批量导入：模板下载、预览校验、提交写入
  • 未知成员：可映射或新建
  • 导入报告：错误/跳过行可下载
