## 1. 项目主要是做什么的

健康记录平台是一个面向**个人及家庭成员**的健康数据管理系统，核心目标是帮助用户持续记录、管理和分析日常健康指标，尤其是血压、心率等高频健康数据。

### 1.1 主要解决的问题

- 为个人用户提供日常健康数据记录入口，减少纸面记录和分散存储带来的信息丢失。
- 为家庭场景提供多成员管理能力，支持一个账号维护“自己”和其他家庭成员的健康记录。
- 通过图表、筛选、导出、批量导入等能力，提升健康数据的可追踪性和可复用性。
- 通过角色权限、密码策略、测试体系和部署配置，保证系统在产品侧可用、在工程侧可持续迭代。

### 1.2 当前核心能力

- 用户注册、登录、JWT 鉴权、角色权限管理
- 家庭成员管理，支持 Self/自己 保护机制
- 健康记录管理，支持血压、心率、标签、备注、分页和筛选
- 健康数据图表展示与趋势查看
- CSV 导出与批量导入
- 中英文界面支持
- Docker / Kubernetes / Azure Container Apps 部署准备
- Pytest + Playwright 的自动化测试体系

### 1.3 项目定位总结

从产品视角看，这个项目已经不是单纯的“血压记录小工具”，而是在向一个**家庭健康档案与健康数据运营平台**发展。它的重点不只是“录入数据”，而是把**身份、成员、记录、分析、导入导出、国际化和交付质量**串成一个完整闭环。
