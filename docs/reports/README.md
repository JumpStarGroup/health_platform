### 转换为 Word 格式

#### 方法一：使用 Pandoc（推荐）

```bash
# 安装 Pandoc（如果尚未安装）
# Windows: https://pandoc.org/installing.html
# macOS: brew install pandoc
# Linux: apt-get install pandoc

# 转换为 Word 文档（详细版）
pandoc MONTHLY_FEATURE_REPORT_2026-01.md -o 健康记录平台月度报告_2026-01.docx

# 转换为 Word 文档（简洁版）
pandoc MONTHLY_FEATURE_REPORT_2026-01_WORD.md -o 健康记录平台月度报告_简版_2026-01.docx

# 带样式转换（使用自定义模板）
pandoc MONTHLY_FEATURE_REPORT_2026-01.md --reference-doc=template.docx -o 健康记录平台月度报告_2026-01.docx
```

## 🎨 自定义样式

### Word 模板

如需统一的企业样式，可创建 `template.docx` 模板文件：

1. 在 Word 中创建新文档
2. 设置样式：
   - 标题 1：字体 18pt，加粗，颜色 #1890ff
   - 标题 2：字体 16pt，加粗，颜色 #333
   - 标题 3：字体 14pt，加粗
   - 正文：字体 12pt，行距 1.5
   - 表格：边框 1pt，表头背景色 #f0f0f0
3. 另存为 `template.docx`
4. 使用 Pandoc 转换时引用模板：
   ```bash
   pandoc MONTHLY_FEATURE_REPORT_2026-01.md --reference-doc=template.docx -o output.docx
   ```

### CSS 样式（用于 HTML 导出）

创建 `report-style.css`：

```css

  line-height: 1.6;

```

使用：
```bash
pandoc MONTHLY_FEATURE_REPORT_2026-01.md --css=report-style.css -o report.html
```

## 🔄 更新维护

### 月度报告生成流程

1. **收集信息**（每月最后一周）
   - Git 提交历史：`git log --since="1 month ago"`
   - CHANGELOG.md 更新内容
   - Issue/PR 关闭情况
   - 测试报告和覆盖率

2. **撰写报告**（使用模板）
   - 基于 `MONTHLY_FEATURE_REPORT_TEMPLATE.md`
   - 更新版本号、日期、统计数据
   - 添加新功能说明和截图

3. **审核与发布**
   - 技术审核：开发团队 Review
   - 内容审核：产品经理 Approve
   - 提交到 Git：`docs/reports/MONTHLY_FEATURE_REPORT_YYYY-MM.md`

4. **分发**
   - 转换为 Word/PDF 格式
   - 邮件通知相关干系人
   - 发布到内部文档系统
