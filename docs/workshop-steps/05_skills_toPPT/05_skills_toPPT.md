# Exercise 05: Use Agent Skills to generate a PPT summary

## Scenario

You have now implemented and validated key parts of the Health Platform workshop: local dev setup, a shared AKS deployment model (branch → namespace), a CI/CD pipeline, and security best practices with GitHub Advanced Security.

In a real project, you also need **shareable artifacts** for stakeholders (leaders, security, platform admins, and new engineers). In this exercise, you will use **Agent Skills** to summarize what was delivered and generate a **PPTX deck** automatically.

## Objectives

After completing this exercise, you'll be able to:

- Collect a concise, accurate summary of what changed across earlier exercises
- Turn that summary into a slide outline
- Generate a PPTX deck using the repository's **pptx skill pipeline**
- Store referenced assets under `docs/media` and keep links consistent

## Duration

* **Estimated Time:** 30 minutes
