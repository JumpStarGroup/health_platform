# Task 02 - Generate the PPT deck using the pptx skill pipeline

## Introduction

This repository includes a working PPT generation pipeline driven by the **pptx skill**. It converts curated HTML slides into a `.pptx` file.

## Description

You will update (or reuse) the existing HTML slide templates under `pptx_summary/slides/` and run the generator script to produce a deck.

## Success Criteria

- You generated a PPTX file successfully
- The deck contains an up-to-date summary of earlier exercises
- The generated PPTX is stored in a predictable path and can be shared

## Key Tasks

### 01: Update the slide content (HTML)

<details markdown="block">
<summary><strong>Expand this section for detailed steps</strong></summary>

1. Open the HTML slides folder:
   - `pptx_summary/slides/`

2. Pick one approach:
   - **Option A (recommended):** update existing slide files to match your outline
   - **Option B:** add new HTML slide files and include them in `pptx_summary/generate_ppt.js`

3. Keep slides structured and consistent:
   - 1 title + short subtitle
   - 3–6 bullets per slide
   - Use concrete names from the repo (workflow file, AKS model, GHAS)

</details>

### 02: Generate the PPTX file

<details markdown="block">
<summary><strong>Expand this section for detailed steps</strong></summary>

1. From the repository root, run:

   ```bash
   node pptx_summary/generate_ppt.js
   ```

2. The output is written to:
   - `pptx_summary/health_platform_summary_blue.pptx`

3. Open the file and review:
   - Slide order matches the outline
   - Fonts/colors are consistent
   - No overflow/cut-off text

</details>

### 03: (Optional) Generate an alternative deck via Python

This repo also includes a minimal dependency Python generator.

<details markdown="block">
<summary><strong>Expand this section for detailed steps</strong></summary>

1. Run:

   ```bash
   python tools/generate_latest_features_ppt.py
   ```

2. The script writes to `docs/reports/` (see terminal output for the exact filename).

</details>

## Summary

You've completed this task. You generated a stakeholder-ready PPTX deck from repository content using the pptx skill pipeline.
