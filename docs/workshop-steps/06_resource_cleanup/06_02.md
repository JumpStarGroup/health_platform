# Task 02 - Cleanup GitHub artifacts

## Introduction

As part of this training, you created GitHub artifacts (workflows, issues, pull requests, container images in GHCR) that you may want to clean up. In particular, old container images and workflow runs can accumulate over time.

## Description

In this task, you will remove GitHub workflows, issues, pull requests, and optionally clean up old container images created during the lab exercises.

>**NOTE** As you executed Copilot instructions during this lab, results may vary. Apply these instructions to your actual artifacts.

## Success Criteria

- You have removed or disabled workshop-specific workflows
- You have cleaned up workflow runs (optional)
- You have closed all lab-related issues and pull requests
- You have optionally cleaned up old GHCR container images

## Learning Resources

- [GitHub CLI Reference](https://cli.github.com/manual/gh){:target="_blank"}
- [Managing GitHub Container Registry](https://docs.github.com/en/packages/working-with-a-github-packages-registry/working-with-the-container-registry){:target="_blank"}

## Key Tasks

### 01: Clean Up GitHub Actions Workflows

Delete or disable workshop workflow files.

<details markdown="block">
<summary><strong>Expand this section for detailed steps</strong></summary>

1. Review workflow files:
   ```bash
   ls .github/workflows/
   ```

2. To delete the workshop workflow:
   ```bash
   git rm .github/workflows/Build-Deploy-K8S.yml
   git commit -m "Remove workshop workflow"
   git push
   ```

3. Or to disable without deleting, comment out triggers in the YAML file.

</details>

### 02: Close Issues and Pull Requests

Close any open issues or PRs created during the workshop.

<details markdown="block">
<summary><strong>Expand this section for detailed steps</strong></summary>

#### Using GitHub CLI

```bash
# List open issues
gh issue list --state open

# Close an issue
gh issue close <issue-number>

# List and close PRs
gh pr list --state open
gh pr close <pr-number>
```

#### Using GitHub UI

1. Go to **Issues** or **Pull requests** tab
2. Open each item and click **Close**

</details>

### 03: (Optional) Clean Up GHCR Container Images

Delete old workshop container image tags from GHCR to reclaim storage.

<details markdown="block">
<summary><strong>Expand this section for detailed steps</strong></summary>

1. Navigate to your repository → **Packages**

2. Find `health-platform-backend` and `health-platform-frontend`

3. Select old image versions/tags (e.g., those tagged with your branch name or commit SHA)

4. Click **Delete** and confirm

> **NOTE**: Only delete your workshop-specific image tags. Do not delete shared or production images.

</details>

### 04: Verification

Confirm cleanup is complete.

<details markdown="block">
<summary><strong>Expand this section for detailed steps</strong></summary>

```bash
# Verify no open issues
gh issue list --state open

# Verify no open PRs
gh pr list --state open

# List workflows
ls .github/workflows/
```

Check GitHub UI:
- **Actions** → confirm workflow runs cleaned (optional)
- **Packages** → confirm old images removed (optional)

</details>

## Summary

You've completed this task. Workshop-specific workflows, issues, PRs, and container images have been cleaned up.
