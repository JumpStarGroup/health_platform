# Exercise 01: Set up your development environment

## Scenario

This training will have you implement a proof of concept for the Health Platform solution using DevOps and AI-driven development practices. The customer in this scenario is JumpStarX, a digital healthcare company that provides online health management services. The Health Platform application is a family health management system that tracks blood pressure, heart rate, and other vital signs for household members, and will be used as a prototype for JumpStarX. Your goal is to establish best practices for DevOps setup and AI-assisted development and delivery for this Python/Flask + React based web application.

In this first exercise, you will set up Visual Studio Code and local developer prerequisites for the Health Platform (Python/Flask + React). You will also verify you can run the backend and frontend locally, in preparation for later exercises.

## Objectives

After completing this exercise, you'll be able to:

* Fork and clone a repository
* Install local tools (Python, Node.js, Git, Docker) and recommended VS Code extensions
* Run the backend and frontend locally

## Duration

* **Estimated Time:** 45 minutes
