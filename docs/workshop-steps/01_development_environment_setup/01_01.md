# Task 01 - Prepare your GitHub account

## Introduction

This workshop uses GitHub as the primary learner interface: you will fork the repo, create a branch, push changes, and let GitHub Actions deploy your branch to a shared AKS cluster.

## Description

During this task you will ensure your GitHub account is ready to participate:

- You can fork the repository.
- You can push a branch.
- GitHub Actions can run in your fork.

## Success Criteria

- You can sign in to GitHub and access your forked repository
- GitHub Actions are enabled in your fork

## Learning Resources

- [Using GitHub Actions in your project](https://docs.github.com/en/actions/learn-github-actions/introduction-to-github-actions){:target="_blank"}

## Key Tasks

### 01: Sign in to your GitHub account

Before you setup GitHub Enterprise, choose the GitHub account you would like to connect to GitHub Enterprise and login to that account.

### 02: Verify GitHub Actions are enabled

Your fork must allow GitHub Actions to run workflows.

<details markdown="block">
<summary><strong>Expand this section for detailed steps</strong></summary>

1. Open your forked repository on GitHub.

2. Go to **Settings** → **Actions** → **General**.

3. Ensure actions are enabled (the exact options vary by organization policy).

</details>

## Summary

You've completed this task. Your GitHub account is ready for the workshop.
