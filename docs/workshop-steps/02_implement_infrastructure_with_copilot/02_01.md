# Task 01 - Understand the shared AKS deployment model

## Introduction

In this workshop version, the cloud infrastructure (shared AKS cluster) is pre-provisioned by the workshop admin. Learners do **not** create Azure resources.

Instead, you will deploy to a **shared AKS cluster** using an isolated **namespace derived from your Git branch name**.

## Description

During this task you will use Copilot to understand:

- How **branch = namespace** works
- What the admin has configured (cluster access, RBAC, quota/limitrange guardrails, and GHCR pull credentials)
- What the GitHub Actions workflow will do on your behalf

## Success Criteria

- You can explain the branch-to-namespace concept
- You know where to find the required configuration and secrets checklist
