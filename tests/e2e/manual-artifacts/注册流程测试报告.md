# 注册流程测试报告

测试时间：2026-08-06  
环境：前端 http://localhost:3000，后端 http://localhost:5000，Playwright Chromium，无头浏览器

## 结果

| 场景 | 结果 | 说明 |
|---|---|---|
| 登录页可访问 | 通过 | `/login` 正常加载 |
| 注册页可访问 | 通过 | `/register` 正常加载 |
| 邮箱不能为空 | 通过 | 空邮箱提交被前端校验拦截 |
| 密码少于 8 位 | 部分通过/发现缺陷 | 5 位被拦截，但实现规则为最少 6 位，6–7 位可提交，不符合需求 |
| 正常注册 | 通过 | 注册成功后自动跳转登录页 |
| 注册后登录 | 通过 | 新账号可登录并跳转 `/dashboard` |

## 缺陷

注册页面密码校验规则为 `min: 6`，而需求要求少于 8 位拒绝。位置：[Register.jsx](../../../frontend/src/pages/Register.jsx)。应将最小长度改为 8，并补充 6、7 位边界测试。
